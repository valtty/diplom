# Fleur Nails (дипломный проект)

Сайт нейл-студии `Fleur Nails` на Django с онлайн-записью, акциями, блогом, сертификатами, бонусной системой и тестовой интеграцией оплаты.

## Что реализовано

- Интегрирована тестовая логика оплаты (`PaymentTransaction`, `PaymentLog`, webhook `payments/yookassa/webhook/`).
- Реализованы сценарии:
  - предоплата 20% при записи;
  - покупка подарочного сертификата;
  - обработка callback и логирование подписи;
  - базовая модель для возвратов через статус `refunded`.
- Добавлены новые разделы: `акции`, `сертификаты`, `блог`, расширенный `профиль`.
- Добавлена бонусная система и транзакции бонусов.

## Переключение с песочницы на боевой режим

1. Откройте `lash_salon/settings.py`.
2. Замените:
   - `YOOKASSA_SHOP_ID`
   - `YOOKASSA_SECRET_KEY`
   на боевые значения из личного кабинета ЮKassa.
3. Обновите callback URL в кабинете ЮKassa:
   - `https://<ваш-домен>/payments/yookassa/webhook/`
4. Выключите debug и настройте https в проде.

## Локальный запуск

```bash
python manage.py makemigrations
python manage.py migrate
python manage.py runserver
```

## Ngrok для webhook в разработке

```bash
ngrok http 8000
```

Используйте выданный https URL для callback в песочнице.
